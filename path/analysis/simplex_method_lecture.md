# Лекция: симплекс-метод для задач линейного программирования

## 1. Зачем нужен симплекс-метод

Задача линейного программирования состоит из двух частей:

- целевая функция, которую нужно максимизировать или минимизировать;
- система линейных ограничений.

Геометрически при двух переменных можно представить допустимую область как многоугольник. Оптимум линейной функции достигается в одной из его вершин. Симплекс-метод делает то же самое систематически, но не требует каждый раз рисовать график.

[

## 3. Базис и небазисные переменные

В начальной задаче:

[
x_1=x_2=0.
]

Тогда из системы сразу получаем:

[
x_3=36,quad x_4=20,quad x_5=40.
]

Переменные (x_3,x_4,x_5) — базисные, а (x_1,x_2) — небазисные.

Главная идея: в каждом базисном решении большая часть переменных равна нулю, а значения остальных находятся из системы.

[

[

[

При принятом в лекции соглашении для задачи на максимум отрицательная оценка показывает, что соответствующая переменная ещё может увеличить целевую функцию.

Поэтому выбираем (x_2), потому что:

## 11. Как запомнить весь алгоритм

Запомни цепочку:

**Каноническая форма → начальный базис → оценки → входящая переменная → отношения B/a → выходящая переменная → разрешающий элемент → пересчёт → новые оценки → повтор.**

Самое важное правило:

1. Смотри на оценки и выбирай переменную, которая улучшает максимум.
2. По её столбцу считай только положительные отношения (B/a).
3. Минимальное положительное отношение определяет выходящую переменную.
4. Пересечение этих строки и столбца — разрешающий элемент.
5. После пересчёта снова считай оценки.

## 12. Частые ошибки

### Нельзя брать отрицательное отношение

Правило отношений применяется только к положительным коэффициентам разрешающего столбца.

### Нельзя случайно менять базис

После каждого шага надо явно записывать, кто вошёл и кто вышел.

### Нельзя останавливаться после первого пересчёта

Пока критерий оптимальности не выполнен, симплекс-метод продолжается.

### Не путай (B) и коэффициенты целевой функции

(B) — правая часть ограничений, а (Cб) — коэффициент соответствующей базисной переменной в целевой функции.
