## Как решать аналогичную задачу самостоятельно

Для каждой новой задачи делай один и тот же шаблон:

### 1. Приведи ограничения к равенствам

Для (le) добавляй дополнительную переменную.

### 2. Найди начальный базис

Обычно в таких задачах базис образуют добавленные переменные.

### 3. Поставь небазисные переменные в ноль

Получишь начальное базисное решение.

### 4. Посчитай (Delta_j)

Для соглашения этой лекции:

[
Delta_j=sum c_i a_{ij}-c_j.
]

### 5. Выбери входящую переменную

Для максимизации при данной записи оценок бери отрицательную оценку, которая сильнее всего уменьшает строку оценок.

### 6. Посчитай отношения

[
	heta_i=rac{B_i}{a_{ik}},
]

но только там, где:

[
a_{ik}>0.
]

### 7. Выбери минимум

Минимальное положительное отношение задаёт выходящую переменную.

### 8. Пересчитай таблицу

Разрешающий элемент должен стать 1, все остальные элементы разрешающего столбца — 0.

### 9. Повтори

После пересчёта снова считаешь оценки.

### 10. Остановись по критерию

Когда все оценки удовлетворяют критерию оптимальности данной формы таблицы, базисное решение является оптимальным.

Главное, что надо научиться делать руками: **выбирать столбец → считать отношения → выбирать строку → находить разрешающий элемент → пересчитывать таблицу**.
