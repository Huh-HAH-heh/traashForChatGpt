# Шпаргалка: как решать симплекс-методом

## Что делать всегда

1. Привести ограничения к равенствам.
2. Добавить дополнительные переменные для ограничений вида <=.
3. Выписать начальный базис из дополнительных переменных.
4. Небазисные переменные поставить в 0.
5. Построить симплексную таблицу.
6. Посчитать оценки Δj по формуле из лекции:
   
   Δj = Σ(ci * aij) - cj

7. Для максимизации в данной записи выбрать отрицательную оценку для входящей переменной.
8. В её столбце посчитать отношения:
   
   θi = Bi / aik
   
   только для aik > 0.
9. Взять минимальное положительное отношение.
10. Строка этого отношения определяет выходящую переменную.
11. Пересечение строки и столбца — разрешающий элемент.
12. Нормировать разрешающую строку, затем занулить разрешающий столбец в остальных строках.
13. Пересчитать Δj.
14. Повторять до выполнения критерия оптимальности.

## На нашей задаче

f = 12x1 + 15x2 -> max

6x1 + 6x2 <= 36
4x1 + 2x2 <= 20
4x1 + 8x2 <= 40
x1, x2 >= 0

После добавления x3, x4, x5:

6x1 + 6x2 + x3 = 36
4x1 + 2x2 + x4 = 20
4x1 + 8x2 + x5 = 40

Начальный базис: x3, x4, x5.

Первый входящий: x2, потому что Δ2 = -15.

Отношения:

36/6 = 6
20/2 = 10
40/8 = 5

Выходит x5. Разрешающий элемент = 8.

После пересчёта:

базис x3, x4, x2;
Δ1 = -4.5.

Вводим x1.

Отношения:

6/3 = 2
10/3 ≈ 3.33
5/0.5 = 10

Выходит x3. Разрешающий элемент = 3.

После второго пересчёта все оценки неотрицательны, значит получено оптимальное решение.

Ответ:

x1 = 2
x2 = 4
x3 = 0
x4 = 4
x5 = 0
fmax = 84

## Как быстро проверить себя

Подставь найденные x1 и x2 в исходные ограничения:

6*2 + 6*4 = 36
4*2 + 2*4 = 16 <= 20
4*2 + 8*4 = 40

Все ограничения выполнены.

## Что говорить преподавателю

«Сначала я привожу задачу к канонической форме с помощью дополнительных переменных. Затем выбираю начальный базис. По строке оценок определяю переменную, которая должна войти в базис. По минимальному положительному отношению свободного члена к коэффициенту разрешающего столбца определяю выходящую переменную. После выбора разрешающего элемента пересчитываю таблицу. Повторяю процедуру до выполнения критерия оптимальности. В данном примере получаю x1=2, x2=4 и fmax=84».
