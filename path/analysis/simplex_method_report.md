# Отчёт по материалам лекции: симплекс-метод

## 1. Исходные материалы

В репозитории в каталоге `path/1`–`path/7` находятся семь JPEG-изображений, загруженных через Base64. По метаданным каждый исходный файл имеет расширение `.jpg`. Изображения визуально восстановлены из Base64 и проанализированы.

Материалы представляют собой фотографии экрана с одной лекцией по решению задач линейного программирования симплекс-методом.

## 2. Содержание изображений

### Изображение 1

Слайд «Каноническая форма задачи».

Вводится понятие канонической формы для задачи линейного программирования. На слайде зафиксированы три характерных условия:

- целевая функция стремится к максимуму;
- ограничения записаны как равенства с неотрицательной правой частью;
- все дополнительные переменные неотрицательны.

Это необходимо для перехода к форме, удобной для применения симплекс-метода.

### Изображение 2

Слайд «Решим задачу».

Рассматривается пример:

[
f=12x_1+15x_2 ightarrow max
]

при ограничениях:

[
6x_1+6x_2le36,
]

[
4x_1+2x_2le20,
]

[
4x_1+8x_2le40,
]

[
x_1ge0,quad x_2ge0.
]

Для приведения к канонической форме вводятся дополнительные переменные:

[
x_3,;x_4,;x_5ge0.
]

Получается система равенств:

[
6x_1+6x_2+x_3=36,
]

[
4x_1+2x_2+x_4=20,
]

[
4x_1+8x_2+x_5=40.
]

Целевая функция записывается как:

[
f=12x_1+15x_2+0x_3+0x_4+0x_5ightarrowmax.
]

### Изображение 3

Слайд «Базисное решение задачи».

Показывается принцип получения начального базисного решения: небазисные переменные (x_1,x_2) принимаются равными нулю.

Базисными становятся дополнительные переменные:

[
x_3=36,quad x_4=20,quad x_5=40.
]

Это начальная вершина допустимой области.

### Изображение 4

Показан следующий этап после приведения задачи к канонической форме: начальная симплексная таблица и расположение базисных/небазисных переменных.

Смысл таблицы:

- столбец «Базис» содержит базисные переменные;
- столбец (C) — коэффициенты этих переменных в целевой функции;
- столбец (B) — текущие значения базисных переменных;
- столбцы (x_j) содержат коэффициенты небазисных переменных в ограничениях;
- специальная строка используется для пересчёта целевой функции и относительных оценок.

### Изображение 5

Раскрывается состав исходной симплексной таблицы.

На слайде объясняется, что коэффициенты при базисных переменных записываются в столбце «Базис», коэффициенты в целевой функции — в строке/столбце (C), свободные члены ограничений — в (B), а коэффициенты при небазисных переменных (x_j) — в соответствующих столбцах.

### Изображение 6

Показана строка оценок и формулы:

[
f=sum c_i b_i,
]

[
Delta_j=sum c_i a_{ij}-c_j.
]

То есть по текущему базису вычисляется значение целевой функции и относительные оценки для решения вопроса о вводе очередной переменной в базис.

### Изображение 7

Показан алгоритм пересчёта после выбора разрешающего элемента.

В частности, используются отношения:

[
b_k=rac{b_r}{a_{rk}},
]

[
a_{kj}=rac{a_{rj}}{a_{rk}},
]

[
a_{kr}=rac{1}{a_{rk}},
]

а также пересчёт элементов главного столбца и оценки (Delta_r).

Главный элемент симплексной таблицы выбирается на пересечении разрешающей строки и разрешающего столбца.

## 3. Основная идея лекции

Вся последовательность материалов описывает один алгоритм:

1. привести задачу линейного программирования к канонической форме;
2. выделить базисные и небазисные переменные;
3. построить начальную симплексную таблицу;
4. вычислить значение целевой функции и относительные оценки;
5. выбрать переменную, которая должна войти в базис;
6. определить переменную, которая выйдет из базиса по правилу минимального положительного отношения;
7. выбрать разрешающий элемент;
8. пересчитать таблицу;
9. повторять процесс до выполнения условия оптимальности.

## 4. Вывод

Материалы логически представляют одну тему — ручной симплекс-метод для задач линейного программирования. Семь изображений образуют последовательность от определения канонической формы до формул пересчёта симплексной таблицы. Численный пример на фотографиях позволяет пройти этот алгоритм полностью и получить оптимальное решение. Главная трудность для начинающего состоит не в арифметике, а в правильном выборе входящей переменной, выходящей переменной и разрешающего элемента.

## 5. Результат численного примера

Для приведённой на слайде задачи оптимальное решение:

[

[
