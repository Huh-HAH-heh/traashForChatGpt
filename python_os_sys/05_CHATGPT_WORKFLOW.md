# Как использовать этот пакет с ChatGPT

## Если я задаю вопрос

Сначала определи, к какой теме относится вопрос:

- `os` / файловая система -> `01_THEORY.md` + `02_REFERENCE.md`
- `sys.argv` / CLI / `sys.exit` -> `01_THEORY.md` + `04_QA.md`
- `sys.path` / import -> `01_THEORY.md` + `04_QA.md`
- конкретная функция -> `02_REFERENCE.md`
- нужно научиться писать -> `03_PRACTICE.md`
- ошибка -> сначала диагностировать, а не угадывать

## Формат эффективного ответа

1. Сначала конкретный ответ.
2. Затем минимальный рабочий пример.
3. Затем одна фраза «почему».
4. Если это навык — дать маленькое упражнение.
5. Не пересказывать весь урок, если вопрос узкий.

## Если я не понимаю

Не давать длинную теорию. Разбить задачу на:

`что происходит -> почему -> минимальный пример -> моя попытка -> проверка`.

## Если я прошу пройти курс

Не заставлять меня переписывать лекцию. Проверять понимание практикой.

Приоритет:

1. понять модель;
2. написать код без копирования;
3. получить ошибку/результат;
4. объяснить результат;
5. повторить без подсказки.

## Главное

Цель этого пакета — сделать так, чтобы вопрос вроде:

> «Как найти все PNG внутри папки?»

сразу приводил к:

`os.walk` / `pathlib.rglob` -> короткий пример -> объяснение -> упражнение.

Не надо отвечать списком из 30 функций, если для задачи нужны две.
