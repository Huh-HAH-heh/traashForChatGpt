# Быстрые ответы

## Что такое `os`?

Стандартный модуль для взаимодействия с операционной системой: файлы,
каталоги, окружение и системные операции.

## Что такое `sys`?

Модуль с интерфейсом к Python-интерпретатору и параметрам процесса:
аргументы запуска, пути импорта, исполняемый интерпретатор и завершение.

## `os` или `sys`?

```text
ОС / файловая система / окружение -> os
Python runtime / argv / import path -> sys
```

## Почему `open("file.txt")` иногда не находит файл?

Относительный путь считается от текущего рабочего каталога.

Проверить:

```python
import os
print(os.getcwd())
```

## Как проверить путь?

`os.path.exists(path)` — существует ли объект.

`os.path.isfile(path)` — является ли файлом.

`os.path.isdir(path)` — является ли каталогом.

## Как пройти вложенные каталоги?

`os.walk(root)` или современно `Path(root).rglob("*")`.

## Что в `sys.argv`?

Аргументы командной строки. Для:

```text
python app.py abc 123
```

получим примерно:

```python
["app.py", "abc", "123"]
```

## Почему мой первый аргумент — `sys.argv[1]`?

Потому что `sys.argv[0]` — имя/путь запускаемой программы.

## Как избежать `IndexError`?

Проверить `len(sys.argv)` до обращения к индексу.

## Что такое `sys.path`?

Список мест, в которых Python ищет импортируемые модули.

## Можно ли менять `sys.path`?

Да, но ручной `append` не должен быть стандартным способом чинить архитектуру
проекта. Сначала проверь структуру проекта и окружение.

## Что такое `os.environ`?

Переменные окружения текущего процесса.

```python
os.environ.get("NAME")
os.environ.get("NAME", "default")
```

## `os.system` или `subprocess.run`?

Для современного кода обычно `subprocess.run`: лучше контролируются аргументы,
stdout/stderr и код возврата.

## Что делает `sys.exit(1)`?

Завершает программу с кодом 1. Ненулевой код обычно означает ошибку.

## Что делает `os.path.join()`?

Собирает путь из компонентов с учётом правил платформы.

## `basename` и `dirname`?

Для условного пути `C:/data/image.png`:

```text
basename -> image.png
dirname  -> C:/data
```

## Что делает `splitext`?

Разделяет имя и расширение:

```python
os.path.splitext("image.png")
# ("image", ".png")
```

## Почему `os.walk` возвращает три значения?

Потому что на каждом уровне дерева он даёт:

```python
root, dirs, files
```

## Как узнать размер файла?

`os.path.getsize(path)` или `Path(path).stat().st_size`.

## Что проверять при `FileNotFoundError`?

```python
print(os.getcwd())
print(os.path.abspath(path))
print(os.path.exists(path))
```

## Что проверять при `ModuleNotFoundError`?

```python
print(sys.executable)
print(sys.path)
```

## Что учить наизусть?

Минимум:

```text
os.getcwd
os.listdir
os.walk
os.environ
os.path.join
os.path.exists
os.path.isfile
os.path.isdir
os.path.abspath
os.makedirs
os.remove
os.rename

sys.argv
sys.path
sys.executable
sys.exit
```

Остальное — уметь быстро найти в документации.

## Что использовать в новом проекте?

Для путей часто `pathlib`, для процессов — `subprocess`.
`os` и `sys` всё равно нужно понимать, потому что это фундамент стандартной библиотеки.
