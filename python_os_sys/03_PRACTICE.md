# Практика

Не копируй решение сразу. Сначала напиши сам.

## Уровень 1

### 1. Где я?

Вывести текущий каталог, абсолютный путь и путь к Python-интерпретатору.

Использовать `os.getcwd()`, `os.path.abspath()`, `sys.executable`.

### 2. Что лежит рядом?

Получить содержимое текущего каталога и отдельно вывести файлы и каталоги.

### 3. Построение пути

Из:

```python
root = "data"
category = "images"
filename = "unit.png"
```

собрать корректный путь без ручной склейки.

### 4. Проверка пути

Получить путь через `sys.argv` и вывести одно из:

```text
does not exist
file
directory
```

### 5. Создание дерева

Создать:

```text
sandbox/
  input/
  output/
  logs/
```

Повторный запуск не должен падать.

## Уровень 2

### 6. Найти все PNG

Рекурсивно найти все `.png` без сторонних библиотек.

### 7. Подсчитать файлы

Для каталога вывести число файлов, каталогов, PNG и TXT.

### 8. Самый большой файл

Рекурсивно найти файл с максимальным размером и вывести путь + размер.

### 9. Числовая сортировка

Для:

```text
1.txt
2.txt
10.txt
11.txt
```

получить порядок 1, 2, 10, 11, а не лексикографический 1, 10, 11, 2.

### 10. Переменная окружения

Прочитать `APP_MODE` и использовать `development`, если переменной нет.

### 11. CLI-утилита

Сделать:

```text
python files.py <directory>
```

которая считает все файлы внутри дерева. Ошибки аргументов должны давать
ненулевой код завершения.

## Уровень 3 — мини-проект

### File Inspector

```text
python inspector.py <path>
```

Для файла вывести тип, имя, расширение, размер и абсолютный путь.

Для каталога — тип, число файлов и число каталогов.

Для отсутствующего пути — понятную ошибку.

### File Finder

```text
python finder.py <directory> <extension>
```

Рекурсивно найти все файлы выбранного расширения.

### External Process

Запустить другую Python-программу через `subprocess.run()`, передать ей
аргументы и обработать код возврата, stdout и stderr.

## Контроль без подсказки

1. Найти все файлы определённого расширения рекурсивно.
2. Получить абсолютный путь.
3. Проверить file/directory.
4. Создать каталог, если его нет.
5. Принять аргумент командной строки.
6. Прочитать env-переменную с default.
7. Объяснить, почему относительный путь иногда «не работает».
8. Объяснить `sys.path`.
9. Запустить внешний процесс и получить stdout.
10. Объяснить `os.system` против `subprocess.run`.

## Финальная задача

Сделать `project_report.py`:

```text
python project_report.py <root>
```

Вывод:

```text
Project: <absolute path>
Files: N
Directories: N
Python files: N
C# files: N
Largest file: <path>
Largest file size: N
```

Затем добавить опцию:

```text
--ext .png
```

которая показывает число файлов выбранного расширения.

Проверить программу на пустом каталоге, несуществующем пути, одном файле,
вложенных каталогах, пробелах в имени и отсутствии аргумента.
