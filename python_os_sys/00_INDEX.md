# Python `os` + `sys` — быстрый учебный пакет

Практический слой поверх курса Stepik «Курс по модулям в Python: os и sys» (курс 253550).

## Как проходить

1. `01_THEORY.md` — понять модель.
2. `02_REFERENCE.md` — быстрый справочник.
3. `03_PRACTICE.md` — задачи руками.
4. `04_QA.md` — ответы на типовые вопросы.
5. В конце решить контрольные задачи без подсказки.

## P0 — знать практически

`import`, `os.getcwd()`, `os.listdir()`, `os.chdir()`, `os.environ`,
`os.path.join()`, `exists()`, `isfile()`, `isdir()`,
`basename()`, `dirname()`, `abspath()`, `splitext()`,
`os.makedirs()`, `os.rename()`, `os.remove()`, `os.rmdir()`,
`sys.argv`, `sys.path`, `sys.executable`, `sys.exit()`.

## P1 — понимать

`os.walk()`, `os.scandir()`, `os.stat()`, переменные окружения,
поиск импортируемых модулей, stdout/stderr и запуск процессов.

## P2 — знать по названию

Редкие платформенные атрибуты и низкоуровневые операции. Их не надо зубрить.

## Главная цель

Уметь по задаче быстро выбрать правильный инструмент, написать маленький
тест и проверить результат.

Для нового кода часто удобнее `pathlib` для путей и `subprocess` для процессов,
но понимание `os`/`sys` остаётся базой.
