# traashForChatGpt

Репозиторий используется как мост для передачи изображений через текстовые Base64-файлы.

## Структура

`path/<номер>/` — одно изображение.

Например:

```text
path/
├── 1/
│   ├── 1.txt
│   ├── 2.txt
│   └── ...
├── 2/
│   └── 1.txt
├── 3/
│   └── ...
└── 6/
    └── 1.txt
```

Если изображение не помещается в один текстовый файл, оно разбивается на несколько частей. Части имеют числовые имена `1.txt`, `2.txt`, `3.txt` и т. д.

## Как восстановить изображение

1. Открыть `path/`.
2. Найти директорию с нужным номером. Каждая такая директория соответствует отдельному изображению.
3. Получить все `.txt` внутри директории.
4. Отсортировать файлы **по числу в имени**, а не лексикографически.
5. Склеить содержимое файлов без изменения данных.
6. Удалить только переносы строк/пробелы, если они были добавлены при хранении Base64.
7. Декодировать полученную строку Base64 в бинарный файл изображения.
8. Проверить сигнатуру и открыть полученный PNG.
9. Для получения самого нового изображения использовать директорию с максимальным номером.

### PowerShell: собрать одну директорию

Например, для `path/6`:

```powershell
$dir = ".\path\6"
$out = ".\restored.png"

$b64 = Get-ChildItem $dir -Filter "*.txt" |
    Sort-Object { [int]$_.BaseName } |
    ForEach-Object { Get-Content $_.FullName -Raw } |
    Out-String

$b64 = $b64 -replace "\s", ""
[IO.File]::WriteAllBytes(
    $out,
    [Convert]::FromBase64String($b64)
)
```

Результат: `restored.png`.

## Как создаётся Base64

Для одного PNG:

```powershell
[Convert]::ToBase64String(
    [IO.File]::ReadAllBytes("C:\Users\User\Documents\ForChatGpt\resorses\image.png")
) | Set-Content image.txt
```

Большой Base64-файл затем можно разделить на части и положить в одну числовую директорию.
