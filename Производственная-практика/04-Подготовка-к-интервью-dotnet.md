# 04. Подготовка к техническим отборам: .NET и SRE

## Цель

Подготовиться к двум смежным, но разным техническим направлениям:

1. Т-Банк SRE — ближайший весенний отбор 2027 года.
2. C#/.NET Backend — долгосрочная специализация и дополнительная возможность трудоустройства.

Не смешивать SRE с обычной .NET-разработкой: в SRE больше инфраструктуры, надёжности, Linux, мониторинга и автоматизации эксплуатации.

Ориентир по нагрузке: 1,5–2 часа в день. Приоритет — практика в коде и терминале, а не только просмотр материалов.

## Ближайшая цель — Т-Банк SRE

Официальная страница: https://education.tbank.ru/start/sre_engineer/

### Подтверждённые даты

- До 31 января 2027 — заявка и регистрация.
- 25–31 января — экзамен по программированию.
- 2–4 февраля — тест по основам SRE для прошедших первый этап.
- После — интервью с командами.
- Старт стажировки — весна 2027 года.

### Что указано в требованиях

- Навыки программирования на любом языке.
- IaC, CI/CD, DevOps-практики и облака.
- Docker, Git, HTTP/HTTPS.
- Дополнительные плюсы: SLA, логи, метрики и трейсинг.

В качестве основного языка для программного экзамена использовать C# либо Python — тот, на котором можно наиболее надёжно решать задачи. Не учить новый язык только ради отбора.

## Календарь подготовки SRE

### 18–30 ноября — инвентаризация базы

- Проверить C# или Python: типы данных, коллекции, функции, исключения.
- Повторить алгоритмы и структуры данных: массивы, строки, словари, множества, сортировки, поиск.
- Проверить Git: ветки, commit, merge, конфликты.
- Повторить HTTP/HTTPS, клиент-сервер, DNS, IP, порты.

Результат: понимать, что именно уже умеешь, и составить список пробелов.

### 1–14 декабря — Linux, сети и контейнеры

- Linux: файловая система, пользователи и права, процессы, службы, systemd, журналы.
- Сети: TCP/UDP, IP, DNS, маршрутизация на базовом уровне, HTTP/HTTPS, TLS в общих чертах.
- Docker: образы, контейнеры, тома, сети, переменные окружения.
- Docker Compose: несколько сервисов, зависимости, healthcheck, логи.

Практический результат: самостоятельно поднять приложение и БД в Compose, проверить доступность, изучить логи и устранить намеренно внесённую ошибку.

### 15–28 декабря — CI/CD и автоматизация

- Что такое pipeline и стадии сборки, тестирования и публикации.
- GitHub Actions или GitLab CI.
- Переменные, secrets, artifacts.
- Идемпотентность и повторяемость инфраструктурных операций.
- Основы Infrastructure as Code: зачем нужен Terraform/Ansible, декларативный подход, состояние инфраструктуры.
- Разница между ручным развертыванием и автоматизированным.

Практический результат: pipeline, который собирает .NET-приложение и запускает тесты. Не хранить секреты в репозитории.

### 29 декабря – 11 января — наблюдаемость и надёжность

- Логи, метрики, трассировки: зачем нужны и чем отличаются.
- Prometheus и Grafana на базовом уровне.
- Алерты и пороги.
- SLA, SLI, SLO, error budget — различия и назначение.
- Базовая диагностика сервиса: CPU, RAM, диск, сеть, ошибки приложения.
- Runbook: что делать при типовой аварии.

Практический результат: развернуть простую тестовую схему мониторинга или изучить её на готовом стенде.

### 12–24 января — экзаменационная подготовка

- Практиковать задачи на выбранном языке.
- Повторить Linux, сети, HTTP, Docker, Git.
- Разобрать CI/CD и IaC.
- Повторить наблюдаемость, SLA/SLI/SLO.
- Провести пробный экзамен без подсказок и с ограничением времени.
- Проверить требования к среде, длительности и правилам попытки на платформе Т-Образования.

Не откладывать регистрацию на 31 января. Сначала зарегистрироваться и изучить описание экзамена, затем закрывать пробелы по реальной программе.

## Долгосрочный блок C#/.NET Backend

### C# и базовая платформа

- ООП: инкапсуляция, наследование, полиморфизм, абстракция.
- Интерфейсы и абстрактные классы.
- Value Types и Reference Types.
- Generics и коллекции.
- Исключения.
- LINQ: Where, Select, GroupBy, Join, Any, FirstOrDefault.
- IEnumerable и IQueryable.
- async/await, Task, CancellationToken.
- Dependency Injection.

### ASP.NET Core

- Controllers / Minimal API.
- Middleware и request pipeline.
- HTTP-методы, статус-коды, REST.
- DTO, валидация, конфигурация и логирование.
- Обработка ошибок.

### PostgreSQL и EF Core

- SELECT, JOIN, GROUP BY, индексы и транзакции.
- DbContext, DbSet, миграции.
- Code First и связи сущностей.
- Change Tracking.
- N+1 и базовая оптимизация запросов.

### Тестирование и инженерный процесс

- Unit Tests и Integration Tests.
- xUnit или NUnit.
- Arrange / Act / Assert.
- Mock и подмена зависимостей.
- API-тесты.
- Git Pull Request и Code Review.
- Docker Compose.
- SOLID и базовые архитектурные принципы.

- Слои и границы ответственности.

Для SRE:

- Измерение производительности.

### STT/WORK/TTS

- Интеграция компонентов.
- Запуск и контроль локальных процессов.
- Обработка отказов.
- Безопасное выполнение команд.
- Логирование и автоматизация.

## Тренировочные интервью

Каждую неделю:
1. Один теоретический опрос без подсказок.
2. Одна практическая задача на C# или Python.
3. Одна инфраструктурная задача в Linux/Docker.
4. Разбор собственного проекта.

После каждой тренировки фиксировать вопрос, ответ, пробел, правильное объяснение и дату повторения.

Критерий готовности: способность самостоятельно решить базовую задачу, объяснить ход рассуждений, диагностировать типовую проблему и честно обозначить границы знаний.
